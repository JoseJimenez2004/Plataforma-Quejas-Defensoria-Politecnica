\section*{Introducción}
Este documento presenta el modelo de base de datos del Sistema de Gestión de la DDP, diseñado en \textbf{Tercera Forma Normal (3FN)}. 
El modelo garantiza:

\begin{itemize}[leftmargin=*]
    \item \textbf{1FN:} Atributos atómicos, sin grupos repetitivos, clave primaria definida.
    \item \textbf{2FN:} Cumple 1FN y todos los atributos no clave dependen completamente de la clave primaria.
    \item \textbf{3FN:} Cumple 2FN y no existen dependencias transitivas.
\end{itemize}

\section{Verificación de Tercera Forma Normal (3FN)}
\label{sec:3fn}

\begin{tcolorbox}[title=Verificación 1FN - Atomicidad, colback=green!5!white]
    \begin{itemize}[leftmargin=*]
        \item \textbf{Sin grupos repetitivos:} Todas las columnas son atómicas.
        \item  \textbf{Clave primaria definida:} Todas las tablas tienen clave primaria.
        \item  \textbf{Atributos atómicos:} Cada columna contiene un solo valor.
    \end{itemize}
\end{tcolorbox}

\begin{tcolorbox}[title=Verificación 2FN - Dependencia Completa, colback=green!5!white]
    \begin{itemize}[leftmargin=*]
        \item \textbf{Tablas con clave simple:} Dependencia completa.
        \item  \textbf{Tablas con clave compuesta:} per\_usuario\_rol y doc\_documento\_version verificadas.
        \item  \textbf{Eliminación de dependencias parciales:} No existen.
    \end{itemize}
\end{tcolorbox}

\begin{tcolorbox}[title=Verificación 3FN - Dependencias Transitivas, colback=green!5!white]
    \begin{itemize}[leftmargin=*]
        \item  \textbf{exp\_queja:} No depende de cat\_subdefensoria.nombre.
        \item  \textbf{per\_persona:} No depende de cat\_unidad\_academica.nombre.
